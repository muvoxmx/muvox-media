# muvox-media

Assets de marketing de Muvox hospedados públicamente para que las herramientas de
programación de redes (Buffer) puedan leerlos por URL.

Todo lo que está aquí es material que se publica en redes de todas formas. No hay
código, credenciales ni datos de clientes.

- `reels/` — videos verticales 1080×1920 con música incrustada (Remotion)
- `social/` — imágenes 1080×1350 para feed y carruseles

Fuente editable: `~/marketing-plans/muvox/assets/`
